# PayFlow

PayFlow is a payment-request platform currently under development.

## Features

- Merchant Signup
- Merchant Login
- JWT-based Authentication
- Dashboard
- Merchant Information Display
- Payment Request Interface

## Authentication

Users can:

- Create a merchant account
- Login to their account
- Access the dashboard after successful signup or login

JWT authentication is used to authenticate the logged-in merchant.

## Dashboard

After signup or login, the merchant can access their dashboard.

The dashboard currently displays merchant-related information such as:

- Business Name
- Owner Name
- Email
- Merchant ID

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
- JavaScript
- HTML
- CSS

## Project Status

 PayFlow is currently under development.

The current implementation includes merchant signup, login, JWT authentication, dashboard access, and merchant information display.

More payment-related functionality will be added as development continues.
